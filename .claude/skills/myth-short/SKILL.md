# Ролик «история за 60 секунд» — главный сценарий

Ты ведёшь пользователя по конвейеру из 7 шагов. После шагов 1, 2 и 4 **остановись и дождись одобрения** — так ролик не придётся переделывать целиком.

Все файлы ролика лежат в `projects/<slug>/`, где `<slug>` — латиница через дефис (`kronos`, `odin-eye`, `anubis`).

```
projects/<slug>/
  brief.md          # тема, угол, факты и источники (шаг 1)
  script.md         # сценарий с разметкой сцен (шаг 2)
  script.txt        # чистый текст для диктора (шаг 2)
  character.md      # библия персонажа и стиля (шаг 3)
  prompts.md        # промпты для картинок/видео по сценам (шаг 3)
  project.json      # сцены для сборки (шаг 3)
  images/01.png ... # картинки или клипы сцен (шаг 4, делает пользователь)
  voice.mp3, subs.srt  # озвучка (шаг 5)
  music.mp3         # музыка, по желанию
  out/final.mp4     # готовый ролик (шаг 6)
  publish.md        # название, описание, хэштеги (шаг 7)
```

## Шаг 1. Тема и угол → `brief.md`
- Если тема не задана — предложи 5 тем с сильным крючком (пример: «Кронос, который съел своих детей», «Бог, которого боялся сам Зевс»).
- По выбранной теме предложи **3 угла подачи** (через страх, через тайну, через несправедливость, через неожиданный факт). Пользователь выбирает один.
- Собери 5–8 ключевых фактов мифа. Отдели **миф** от **исторического факта**. Если версии мифа расходятся — запиши это. Не выдумывай «факты»; если используешь веб-поиск — укажи источники.
- ⏸ Остановись: покажи бриф, дождись «ок».

## Шаг 2. Сценарий → скилл `story-script`
Создай `script.md` и `script.txt`. ⏸ Покажи сценарий целиком, дождись одобрения.

## Шаг 3. Визуал → скиллы `character-bible` и `scene-prompts`
Создай `character.md`, `prompts.md` и `project.json` (шаблон — `templates/project.json`).

## Шаг 4. Картинки (делает пользователь)
Объясни: сгенерировать картинки по `prompts.md` в выбранном сервисе (Midjourney, Leonardo, Ideogram, Flux, ChatGPT и т.д.; для оживления — Kling, Runway, Hailuo, Seedance, Veo) и положить их как `projects/<slug>/images/01.png`, `02.png`… (клипы — `01.mp4`). Можно сразу перейти к шагам 5–6: вместо отсутствующих картинок будут заглушки — так удобно проверить тайминг.
⏸ Дождись, когда пользователь скажет, что картинки на месте (или что хочет черновик с заглушками).

## Шаг 5. Озвучка → скилл `voiceover`
`python tools/tts.py projects/<slug>` → `voice.mp3` + `subs.srt`. Если длиннее 59 с — сократи текст, а не ускоряй голос сильнее +10%.

## Шаг 6. Сборка → скилл `video-assembly`
`python tools/build_video.py projects/<slug>` → `out/final.mp4`. Проверь кадры (см. скилл) и сообщи длительность.

## Шаг 7. Публикация → скилл `publish-pack`
Создай `publish.md`.

## Правила качества (проверяй перед сдачей)
- Длительность 45–59 с, вертикаль 1080×1920.
- Первые 2 секунды — крючок, без вступлений и приветствий.
- Новая картинка каждые 3–6 секунд.
- Персонаж выглядит одинаково во всех сценах.
- Последняя фраза закольцовывает ролик с первой (зритель пересматривает).
- Никаких выдуманных исторических фактов; миф подаётся как миф.
