# Озвучка → `voice.mp3` + `subs.srt`

## Бесплатно: edge-tts (по умолчанию)
```bash
pip install -r tools/requirements.txt   # один раз
python tools/tts.py projects/<slug>
```
Параметры:
- `--voice ru-RU-DmitryNeural` (мужской, по умолчанию — для эпики) или `ru-RU-SvetlanaNeural` (женский);
- `--rate -5%` (медленнее = весомее; диапазон −15%…+10%);
- `--pitch -6Hz` (ниже = мрачнее);
- `--words 3` — слов в одном субтитре (2–4).

Скрипту нужен интернет (сервис Microsoft). Если длина > 59 с — сократи `script.txt`, а не разгоняй голос.

## Ударения и произношение
Древние имена TTS часто произносит неверно. Добавь строки в `pronunciations.txt` (общий, в корне) или в `projects/<slug>/pronunciations.txt`:
```
Кронос = Кро́нос
Аид = Аи́д
```
Ударение — символ U+0301 сразу **после** ударной гласной (скопируй из примеров). Замена ищет слово целиком и с учётом регистра, поэтому падежные формы добавляй отдельно (`Кроноса = Кро́носа`). Можно заменять написание целиком: `Ra = Ра`. В субтитрах ударения автоматически убираются.

После озвучки прослушай начало и все имена. Если ударение неверное — добавь в словарь и перезапусти.

## Платно, качественнее: ElevenLabs
Если у пользователя есть ElevenLabs: озвучить `script.txt` там (модель Multilingual v2 или новее, голос низкий «storyteller»), скачать как `projects/<slug>/voice.mp3`. Субтитры тогда соберутся из текста сцен автоматически (тайминг приблизительный) — либо экспортировать SRT из ElevenLabs и положить как `subs.srt`.
Никогда не проси пользователя присылать API-ключ в чат.

## Чек-лист
- Длительность 45–59 с.
- Пауза после крючка и перед кульминацией (поставь «…» или точку в `script.txt`).
- Имена произносятся правильно.
