# Промпты по сценам → `prompts.md` + `project.json`

Источник: `script.md` (сцены) и `character.md` (CHARACTER / STYLE).

## Формула промпта картинки (на английском)
```
<что происходит в кадре>, <CHARACTER дословно, если герой в кадре>, <план и ракурс>, <окружение>, <STYLE дословно>, vertical 9:16
```

## Разнообразие планов (чередуй, не повторяй один план 2 раза подряд)
- **extreme wide** — масштаб, мир, армии, космос (для крючка и кульминации);
- **medium shot** — действие персонажа;
- **close-up / extreme close-up** — глаза, руки, атрибут, эмоция (для напряжения);
- **low angle** — бог могущественный и страшный; **high angle** — герой слабый и маленький;
- **over the shoulder / POV** — погружение.

Крючок (сцена 1) — самый яркий и странный кадр ролика. Композиция — главное в центре по вертикали: верх и низ кадра закрывает интерфейс соцсети, а субтитры идут чуть ниже центра.

## Движение (для `project.json` и видеомоделей)
- Для картинок сборщик делает «эффект Кена Бёрнса»: `motion`: `in` (наезд — напряжение), `out` (отъезд — масштаб, раскрытие), `left`/`right` (панорама — путь, пейзаж), `none`.
- Для видеомоделей (image-to-video) добавь короткий промпт движения: `slow push-in, embers floating, cape moving in wind, subtle head turn` — одно-два действия, без смены сцены. Длина клипа 5 с.

## Формат `prompts.md`
```
# Промпты: <тема>
Референс персонажа (сгенерировать первым):
full body character sheet, <CHARACTER>, neutral grey background, <STYLE>, vertical 9:16

## 01 — крючок (00:00–00:03)
Картинка: ...
Видео (по желанию): ...
Файл: images/01.png

## 02 — ...
```

## Режим «анимация кодом» (без генераторов картинок)
Если пользователь хочет анимацию, а не картинки (или ролик про реального человека, которого нельзя генерировать), не указывай файл картинки, а задай каждой сцене:
- `card` — 1–3 строки КАПСОМ, главное слово или цифра сцены (`"1980\nРОСТОВ-НА-ДОНУ"`, `"35 000"`); не дублируй субтитры, нужен акцент;
- `anim` — `pop` (выпрыгивает и «дышит»), `slide` (строки въезжают с разных сторон), `type` (печатается по букве), `count` (число отсчитывается от 0 — для цифр), `glitch` (цветовой сбой — для крючка и резких поворотов).
Чередуй типы, `glitch` используй не больше 2 раз за ролик. Фон, частицы, вспышки на смене сцен и эквалайзер в такт голосу добавляются автоматически.
Пример: `{"text": "...", "card": "35 000", "anim": "count"}`.

## `project.json` (шаблон — `templates/project.json`)
```json
{
  "title": "Кронос за 60 секунд",
  "scenes": [
    {"image": "images/01.png", "text": "<текст диктора этой сцены>", "motion": "in"},
    {"image": "images/02.mp4", "text": "...", "motion": "none"}
  ]
}
```
- `text` — точный текст диктора этой сцены: по нему сборщик делит длительность озвучки между сценами.
- `duration` (сек) можно задать вручную, если сцена должна быть дольше/короче.
- Для клипов указывай `.mp4`; если пользователь потом заменит клип на картинку — поправь расширение.
