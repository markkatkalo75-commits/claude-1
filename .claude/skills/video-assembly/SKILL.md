# Сборка → `projects/<slug>/out/final.mp4`

Нужен `ffmpeg` (Windows: `winget install ffmpeg`, macOS: `brew install ffmpeg`, Linux: `apt install ffmpeg`).

```bash
python tools/build_video.py projects/<slug>
```
Опции: `--no-subs` (без субтитров), `--music путь.mp3`, `--music-volume 0.15` (0.08–0.25).

## Что делает скрипт
1. Делит длительность озвучки (+0.8 с) между сценами пропорционально `text` (минимум 1.5 с; `duration` в сцене задаёт вручную).
2. Картинки — плавный наезд/отъезд/панорама (`motion`, по умолчанию чередуется); клипы `.mp4` — обрезаются под 9:16 и длительность сцены (короткие зацикливаются).
3. Нет файла сцены → **моушн-графика кодом** (`tools/animate.py`): текст из `card` с анимацией `anim`, эквалайзер в такт голосу, частицы, вспышки на смене сцен. Без `card` — «СЦЕНА N» (черновик тайминга). Рендер ~1.5 с на секунду видео.
4. Вшивает субтитры: `subs.srt` из озвучки, иначе — автоматически из текста сцен.
5. Смешивает голос и музыку (`music.mp3` в проекте), выравнивает громкость до −14 LUFS.

## Проверка (сделай обязательно)
```bash
ffprobe -v error -show_entries format=duration -of csv=p=0 projects/<slug>/out/final.mp4
ffmpeg -v error -y -ss 1 -i projects/<slug>/out/final.mp4 -frames:v 1 projects/<slug>/out/check_01.png
```
Сними 3–4 кадра (начало, середина, конец), посмотри их: субтитры читаются, не перекрывают лицо, персонаж одинаковый, нет заглушек (если это не черновик). Сообщи пользователю длительность и замечания.

## Музыка
Только с разрешённой лицензией: YouTube Audio Library, Pixabay Music, или купленная. Для мифов подходят: dark ambient, epic orchestral, tribal drums. Положи как `projects/<slug>/music.mp3`.

## Частые правки
- Сцена слишком короткая/длинная → добавь `"duration": 4.5` в `project.json`.
- Субтитры мешают картинке → `--no-subs` или правь `style` в `build_video.py` (`MarginV` — отступ снизу, `FontSize` — размер).
- Музыка громкая → `--music-volume 0.1`.
