# Сценарий «история за 60 секунд»

## Объём
- **90–100 слов** — это 52–58 секунд эпичным голосом (`tools/tts.py` по умолчанию говорит ~1.7 слова/с; проверено: 96 слов = 56 с, 123 слова = 72 с — уже слишком длинно).
- **9–12 сцен**, в каждой 1–2 коротких предложения (5–12 слов).

## Структура (тайминг ориентировочный)
| Блок | Время | Задача |
|---|---|---|
| 1. Крючок | 0–3 с | Шок, парадокс или запрет. Одно предложение. Без «Давным-давно», «Сегодня я расскажу», «Знаете ли вы». |
| 2. Кто это | 3–8 с | Кто, где, чем знаменит — одним предложением. |
| 3. Завязка | 8–20 с | Конфликт: чего он хотел / чего боялся / что ему предсказали. |
| 4. Эскалация | 20–42 с | 2–3 поворота, каждый страшнее/неожиданнее предыдущего. |
| 5. Кульминация | 42–52 с | Самый сильный образ истории. |
| 6. Развязка + петля | 52–58 с | Чем закончилось + фраза, которая отсылает к крючку, чтобы ролик хотелось пересмотреть. |

## Приёмы
- Короткие фразы, глаголы, конкретные образы («проглотил», «тысячу лет», «каменное сердце»), а не абстракции («был могущественным»).
- Открытая петля: обещай ответ («Но пророчество было не о нём») и раскрывай позже.
- Цифры и детали повышают доверие: «шестерых детей», «девять ночей».
- Каждое предложение — то, что можно **нарисовать**.
- Говори «по легенде», «греки верили» там, где это миф. Не выдавай миф за историю и не выдумывай деталей, которых нет в источниках.
- Без вопросов к зрителю в середине; вопрос — только в описании или закреплённом комментарии.

## Примеры крючков
- «Этот бог съел собственных детей — и всё равно проиграл».
- «Его имя запрещали произносить даже жрецам».
- «Один отдал глаз — и получил кое-что страшнее мудрости».

## Что создать
1. `projects/<slug>/script.md`:
```
# <Название>
Длительность: ~NN с, слов: NNN

## Сцена 1 — крючок
Текст: ...
Картинка: (что видно в кадре, 1 строка)

## Сцена 2 — ...
```
2. `projects/<slug>/script.txt` — только текст диктора подряд, без заголовков и пометок. Сложные имена с ударением можно добавить в `pronunciations.txt` (см. скилл voiceover).

Перед сдачей посчитай слова и проверь все пункты структуры.
