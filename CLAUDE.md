# claude-1 — студия коротких AI-роликов «история за 60 секунд»

Общайся с пользователем на русском.

Когда просят сделать ролик/шортс/рилс про бога, миф, легенду или историческую личность — используй скилл `myth-short`: он ведёт по шагам и вызывает остальные скиллы (`story-script`, `character-bible`, `scene-prompts`, `voiceover`, `video-assembly`, `publish-pack`).

- Каждый ролик — отдельная папка `projects/<slug>/` (slug латиницей через дефис).
- Инструменты: `tools/tts.py` (озвучка + субтитры), `tools/build_video.py` (сборка ffmpeg). Зависимости: `pip install -r tools/requirements.txt`, ffmpeg.
- Готовые видео (`projects/*/out/`) не коммитятся.
- Не выдумывай исторические факты; миф подавай как миф.
- Никогда не проси присылать API-ключи или токены в чат.
